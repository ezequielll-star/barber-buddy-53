# Barber Hub

"Crea una Web App responsiva diseñada 100% para uso en celulares (Mobile-First) para la gestión de clientes y turnos de una barbería.

Estilo y UX:

Estética minimalista, sobria, elegante y moderna en Modo Oscuro (Dark Mode). Usá tonos negro mate (#121212) y gris carbón (#1E1E1E) para tarjetas, con un color de acento sobrio en tono bronce/dorado mate (#C5A059).

La interfaz debe simular una app móvil nativa, optimizada para usar con una sola mano, con una barra de navegación inferior (Bottom Navigation Bar) con 4 secciones principales: Inicio/Hoy, Clientes, Caja, y Ajustes.

Todos los botones deben ser grandes y fáciles de tocar.*

Sección Inicio/Hoy:

Una lista cronológica de los turnos del día. Cada tarjeta de turno debe mostrar la hora, el nombre del cliente, el servicio y un botón toggle/estado: [Pendiente] -> [En proceso] -> [Finalizado]."
